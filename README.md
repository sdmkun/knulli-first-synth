# Knulli First Synth

TrimUI Brick（Knulli OS）向けの、4 トラックの小さなグルーブボックスです。打ち込みは生成（ジェネラティブ）とトラッカー式の手入力を組み合わせます。GrainBrick のような「Brick で動く楽器アプリ」を作るための土台として作りました。

## 技術選定

| 候補 | 判断 |
|---|---|
| **C++17 + SDL2** | **採用**。SDL のオーディオコールバックでリアルタイム DSP を回せるので、低レイテンシで処理の重さを気にしなくて済む。Knulli（Batocera 系）は EmulationStation 自体が SDL2 を使っているため、追加ランタイムなしで動く。 |
| Python + pygame-ce | Knulli に標準で入っていて（`/userdata/roms/pygame`）、コンパイルなしで試せる。ただ、サンプル単位の DSP を Python で書くと Cortex-A53 では力不足。numpy が入っている保証もない。 |
| LÖVE (Lua) | PortMaster 経由なら動く。ただし DSP が Lua になり、PortMaster にも依存する。 |
| Rust + SDL2 | 選んでも問題ないが、クロスビルドの手間が増えるわりに利点が小さい。 |

依存するのは SDL2 だけです（文字は内蔵の 5x7 ビットマップフォントで描画）。libstdc++ は静的リンクしています。

## 構成

```
src/gfx.*        描画の道具と 5x7 ビットマップフォント（font.h）

```

## ビルド

PC で動作確認（Windows / MinGW g++）：

```powershell
.\scripts\build-windows.ps1
.\build\windows\ksynth.exe
```

Knulli 用（Docker Desktop が必要）：

```powershell
.\scripts\build-knulli.ps1
```

`dist\ports\` の中身を、SD カードの `/userdata/roms/ports/`（SMB 経由なら `\\KNULLI\share\roms\ports`）にコピーします。その後 Knulli のメニューで「ゲームリストを更新」を実行すると、Ports に **KnulliFirstSynth** が表示されます。

```
roms/ports/
├── KnulliFirstSynth.sh
├── KnulliFirstSynth.sh.keys
└── knulli-first-synth/
    ├── ksynth
    └── samples/kits/BASIC/*.wav
```

起動ログは `roms/ports/knulli-first-synth/log.txt` に出力されます（SDL のドライバ、オーディオの設定、コントローラー名と GUID）。

## 操作

M8 のように画面を行き来します。SEQ・PATTERN・INSTR は横に並んでいて SELECT + 左右で移ります。MODS は INSTR の上、MIXER は SEQ の下にあって、SELECT + 上下で移ります。画面上端に今いる画面が出ます。

```
                                      MODS（エンベロープと LFO）
                                       ↑↓ SELECT + 上下
SEQ  ⇄  PATTERN  ⇄  INSTR
4 トラック一覧   選んだトラックの打ち込み   選んだトラックの音色
 ↑↓ SELECT + 上下
MIXER（音量と EVOLVE）
```

基本の操作はどの画面でも同じです。十字キーでカーソルを動かし、A で「置く / 鳴らす / 開く」、A を押したまま十字キーでカーソルの下の値を変えます（左右で細かく、上下で大きく）。B を押したまま A で消す / 元に戻すです。

### どの画面でも効くボタン

| Brick | PC キーボード | 動作 |
|---|---|---|
| 十字キー | 矢印キー / WASD | カーソル移動（押しっぱなしで連続） |
| A | K | 置く / 鳴らす / 開く（画面ごとに下を参照） |
| A + 十字キー | K + 矢印 | カーソルの下の値を変える。左右 = 細かく、上下 = 大きく |
| B + A | L + K | カーソルの下を消す / 初期値に戻す |
| B + 十字キー | L + 矢印 | ドラムのマスのノートコマンドを変える（PATTERN 画面） |
| X | J | GENERATE メニューを開く |
| Y | I | 選んでいるトラックをミューテート（少しだけ変える） |
| L1 / R1 | Q / E | トラックの選択 |
| L2 / R2 | Z / C | ページ（パターンが 16 ステップより長いとき） |
| L3（正面中央上の左） | T | 選んでいるトラックのミュート |
| R3（正面中央上の右） | R | 選んでいるトラックのソロ（もう一度で解除） |
| START | Enter | 再生 / 停止（停止すると頭に戻る） |
| SELECT + 左右 | Tab + 左右 | SEQ / PATTERN / INSTR の切り替え |
| SELECT + 上 / 下 | Tab + 上 / 下 | INSTR ⇄ MODS、SEQ ⇄ MIXER |
| SELECT + B | Tab + L | 選んでいるトラックのアンドゥ（もう一度でリドゥ） |
| SELECT + X | Tab + J | 選んでいるトラックのパターンを消す |
| SELECT + START | Esc | 終了 |

生成・ミューテート・クリア・打ち込みの前には、そのトラックのパターンを 1 段だけ控えています。SELECT + B で戻し、もう一度押すとやり直せます。

### SEQ 画面

4 トラックを 4 列に並べたトラッカー風の一覧です。16 ステップぶんを縦に並べ、スクロールはしません（それより長いパターンは L2 / R2 でページを切り替え）。

- シンセのトラックは音名（3 つまで、それより多いと `+`）、ドラムのトラックは 8 パートの頭文字（K S H O C T R B）を出します
- 一番上の行は BPM / KEY / SCALE / SWING / GRV（グルーヴ）。カーソルを上に出して A + 十字キーで変えます
- SWING は 50%（ハネなし）〜75%。奇数ステップ（2 つ目の 16 分音符）を後ろにずらします。67% くらいで 3 連符のシャッフルです。B + A で 50% に戻ります。ずらす拍は曲の頭から数えるので、奇数の長さのパターンでは 1 周ごとにハネる位置が入れ替わります
- GRV でA を押すとグルーヴの一覧が開きます（下の「グルーヴ」）。A + 十字キーでも順に切り替わり、B + A で NONE に戻ります
- 右肩の EVO は、そのトラックの EVOLVE が入っている印です
- A でそのステップを PATTERN 画面で開きます。B + A でそのステップを消します

### PATTERN 画面

選んでいるトラックの打ち込み画面です。

**シンセのトラック**：1 ステップに 4 つの列（N1〜N4）があり、それぞれ NOTE・V（ベロシティ）・FX（コマンドと値）が並ぶトラッカーです。

- 空いた NOTE で A を押すと、最後に使った音を置きます。A + 左右でスケールの中を 1 音ずつ、A + 上下で 1 オクターブ動きます
- 音の長さは指定しません。トラッカーと同じく、音は同じ列の次のノートか OFF まで鳴り続けます（パターンの終わりで頭に回り込みます）。列の左の縦の線が、音が鳴っている範囲です
- B + A：ノートを消す。空いているところでは OFF を置き、OFF の上ではそれを消します
- V はベロシティ（強さ）で、1〜8 の 8 段階です（6 が標準）。A + 十字キーで変え、B + A で 6 に戻します。新しく置く音は、最後に使った音程とベロシティになります
- FX：コマンドの欄で A + 上下を押すと、コマンドの一覧が開きます（M8 と同じ）。上下で選んで A で決め、B でやめます。A + 左右なら一覧を開かずに順に切り替わります。値の欄で A + 十字キーを押すと値が変わります。B + A で消えます。カーソルを FX に置くと、画面下にそのコマンドの意味が出ます

**ドラムのトラック**：8 パート × 16 ステップのグリッドで、全パートが一度に見えます。右側にカーソルのマスの詳しい中身（ベロシティとコマンド）が出ます。

- 空いたマスで A を押すと叩く音を置きます。置いてあるマスで A を押しても消えず、音が鳴るだけです。消すのは B + A です
- 棒の高さがベロシティです。置いてあるマスで A + 左右を押すと 1〜8 で変わります
- 置いてあるマスで A + 上下（または B + 左右）を押すと、ノートコマンドの一覧が開きます。B + 上下でその値を変えます。コマンドのあるマスは上に頭文字（R / A / K / D / C）が出ます
- 左端のパート名で A + 左右を押すと、そのパートをユークリッドリズムにします（16 ステップに E 個の音をなるべく均等に並べる）。A + 上下は並びを回転（R）します

#### ノートコマンド

1 ステップは 12 ティックに分かれていて、コマンドはティック単位で働きます。

| コマンド | 値 | 動作 |
|---|---|---|
| RET | 1〜11 | ロール。そのステップの間、値のティックごとに打ち直す（3 = 4 連打、4 = 3 連符、6 = 2 連打） |
| ARP | xy（16 進 2 桁） | アルペジオ。元の音・+x 半音・+y 半音を 3 ティックごとに繰り返す（37 = マイナー、47 = メジャー）。音が鳴っている間ずっと続く。A + 左右で y、A + 上下で x |
| KIL | 1〜99 | 値のティックで音を止める（シンセはリリースを飛ばして数 ms で消え、ドラムはそこで切れる） |
| DLY | 1〜11 | 発音を値のティックだけ遅らせる |
| CHA | 0〜99 | その確率（%）でしか鳴らない |

ARP は音程を動かすので、ドラムには効きません。

### GENERATE メニュー

X で、選んでいるトラックの生成メニューが画面の右に開きます。B で閉じます。

- NEW SEED（A か X）：新しい乱数の種で作り直す
- MUTATE（A か Y）：少しだけ変える
- 設定の値を A + 十字キーで変えると、その場でパターンが作り直されます（LEN だけはパターンの長さを変えるだけで、中身はそのまま）。B + A で初期値に戻します
- メロディの設定：OCT（音域の中心）、DENSITY（音の数）、RANGE（音域の広さ）、MOTION（跳躍の多さ）、LENGTH（音の長さ。OFF を置いて表します）、CHORD（和音にする割合）、DYNAMICS（拍に合わせた強弱の付け方。0% ならすべて 6）、SEED
- ドラムの設定：STYLE（FOUR = 4 つ打ち / BREAK / HALF = ハーフタイム / JUNGLE / RANDOM）、DENSITY、VARIATION（ゴーストノート、フィル、ハイハットやフィルのロールの量）、DYNAMICS（骨格の音とダウンビートを強く、ゴーストノートを弱く、フィルはだんだん強く）、SEED
- ドラムのミューテートでは、キックとスネアの骨格（1・3 拍目のキック、2・4 拍目のスネア）は残します
- 同じ設定・同じシードなら毎回同じ結果になります。メロディは KEY と SCALE に合わせて作ります
- メニューを開いてから設定を変えた分は、まとめて 1 回の SELECT + B で戻ります

### INSTR 画面

選んでいるトラックの音色です。A で音を確かめられます。

- TYPE：SYNTH ⇄ DRUM の切り替え（A + 十字キー）。切り替えるとパターンは消えます（SELECT + B で戻せます）
- シンセ：PRESET と、オシレーター・フィルター・ディレイのパラメータ（下の表）。B + A でそのパラメータをプリセットの値に戻します。右側に今の波形（ウェーブテーブルは POS の位置のフレーム）と出力が出ます
- ドラム：KIT と、8 パッドぶんの SAMPLE / PITCH（±24 半音）/ START / END（再生する範囲）/ VOL。右側に選んでいるパッドの波形と START（緑）・END（赤）が出ます
- パッドの SAMPLE（左端のパッド名）で A + 十字キーを押すと、ファイルブラウザが開きます。`samples/` の下のフォルダと WAV が並び、最初は今のキットのフォルダが開きます。上下で選び、右（または A）でフォルダに入り、左で上のフォルダに戻ります。WAV で A を押すと、そのパッドに読み込んで鳴らします（ブラウザは開いたままなので、続けて聴き比べられます）。B で閉じます
- パッドのサンプルを変えると、そのトラックだけのキットのコピーになり、KIT に `*` が付きます。KIT を選び直すと元のキットに戻ります

### MODS 画面

INSTR から SELECT + 上で開く、シンセのエンベロープと LFO の画面です（ドラムのトラックでは使いません）。4 つの枠の間は十字キーで移れます。

| 枠 | パラメータ |
|---|---|
| AMP ENV | 音量の ATTACK / DECAY / SUSTAIN / RELEASE（下に形が出ます） |
| ENV 2 | もう 1 つのエンベロープ（ATTACK / DECAY / SUSTAIN / RELEASE）と、かける先（DEST）、量（AMOUNT、マイナスもあり） |
| LFO 1 / LFO 2 | SHAPE（SINE / TRIANGLE / SAW / SQUARE / S+H）、RATE（0.05〜20Hz）、DEST、AMOUNT（マイナスもあり）、TRIG（FREE = 流しっぱなし / RETRIG = 音ごとに頭から） |

かける先（DEST）は PITCH（最大 ±12 半音）、CUTOFF（最大 ±6 オクターブ）、RESO、POS（ウェーブテーブルの位置やパルス幅）、AMP です。

### MIXER 画面

SEQ から SELECT + 下で開く、4 トラックの音量と EVOLVE の画面です。十字キーの左右でトラック、上下で項目を選びます（L1 / R1 でも選べます）。

- VOLUME：トラックの音量（0〜150%、白い線が 100%）。A + 十字キーで変え、B + A で 100% に戻します。右の縦の棒はそのトラックの出力レベル（-48dB〜0dB、赤は 0dB 近く）
- EVOLVE：再生しながら、パターンが N 周するたびに自動でミューテートします（OFF / 1 / 2 / 4 / 8 / 16 周）。周の切れ目で変わるので、変わった形が次の周の頭から鳴ります。下の緑の棒が次に変わるまでの進み具合です
- AMOUNT：1 回の変化の大きさ（Y のミューテートは 50%）
- MODE：VARY は毎回「元のパターン」から変化させるので、元の雰囲気のまわりを行き来します。DRIFT は今のパターンから変化させるので、だんだん遠くへ離れていきます。A で切り替えます
- VARY の「元のパターン」は、EVOLVE が書いたのではない形になったとき（手で打ち込んだ、生成した、アンドゥした）にそれに置き換わります
- EVOLVE による変化はアンドゥの対象になりません。ミュートしているトラックは変わりません
- 上の帯の LOOP は、再生を始めてから何周したかです

- GROOVE（一番下の行）：グルーヴと、そのタイミングをどれだけかけるか（TIMING）、強弱をどれだけかけるか（VELOCITY）。左右で項目を選びます。グルーヴを選ぶと TIMING と VELOCITY はファイルに保存されていた値になります

### グルーヴ

Ableton Live のグルーヴファイル（.agr）を読み込んで、曲全体のタイミングと強弱に使えます。

- アプリの横の `grooves/` に .agr を入れると、起動時に読み込みます（実機では `roms/ports/knulli-first-synth/grooves/`、PC ではリポジトリの `grooves/`。サブフォルダも見ます）。ビルドスクリプト（build-knulli.ps1）はリポジトリの `grooves/` を `dist` にコピーします。.agr は git には入れていません
- SEQ の GRV で A を押すと一覧が開きます。上下で動かすと、その場でそのグルーヴに切り替わるので、再生しながら聴き比べられます。A で決め、B で開く前のグルーヴに戻ります
- グルーヴの音（ノート）は「その拍の分割（16 分・8 分・3 連）が実際にはどこで鳴ったか」の地図として使います。分割はファイル名（16ths / 8ths / 8T / 16T）か、音の数から決めます。16 分のステップは、その地図の間を直線でつないだ位置に動きます。強弱も同じように、そのステップの位置の強さを音量にかけます
- グルーヴを選んでいる間、SWING は効きません（SWING は NONE のとき用）
- 読めるのは XML の .agr と、新しい Live のバイナリ形式の .agr（中のノートとタイミング・ベロシティの量を読む）です。バイナリ形式はループの長さが読めないので、ノートを含む小節数にします
- RANDOM と QUANTIZE の量は使っていません

### シーケンサーのしくみ

- 1 ステップ = 16 分音符 = 12 ティック。ベロシティは音量にかかります（8 段階。6 が元の音量で、そこから下は 1 段でおよそ 3dB 小さく、7・8 は 1.5dB ずつ大きいアクセント）
- トラックごとにパターンの長さ（1〜64）を変えられ、違う長さにするとポリメーターになります
- スウィングとグルーヴは、1 ステップ 12 ティックの長さそのものを伸び縮みさせて作ります（スウィングなら偶数ステップのティックを長く、奇数ステップを短く）。そのため RET や DLY もハネに合わせて動きます
- 1 ステップに置ける音は 8 つまでです
- ミュートしたトラックは鳴りません。ソロにしたトラックだけが鳴ります
- 音の出ていないトラック（ボイスなし、ディレイの残りもなし）は計算を省きます
- DSP の軽量化：サイン波と LFO は波形テーブル、リミッターは tanh の近似式、位相の折り返しは比較だけ。DLY MIX が 0 のときはディレイの計算を省きます。エンベロープが落ちきったら値を 0 にそろえて、非正規化数で遅くならないようにしています
- 起動直後は、トラック 2 にベースライン、トラック 4 に 4 つ打ちが入っています。START ですぐ鳴ります

### シンセのパラメータ（INSTR 画面）

| 名前 | 内容 |
|---|---|
| WAVE | 波形。SINE / TRIANGLE / SAW / SQUARE / NOISE と、ウェーブテーブル 7 種（WT MORPH = サイン→三角→ノコギリ→矩形、WT PULSE = パルス幅、WT SYNC = ハードシンク、WT VOWEL = 母音 A→E→I→O→U、WT FOLD = ウェーブフォールド、WT HARM = ドローバー風の倍音、WT DIGI = 粗いデジタル） |
| POS | ウェーブテーブルの位置（フレームの間はなめらかにつながる）。SQUARE ではパルス幅（50%〜5%） |
| PITCH | 音程のずらし（±24 半音） |
| DETUNE | 2 つ目のオシレーターのずらし幅（0〜30 セント） |
| SUB | 1 オクターブ下の矩形波の量 |
| NOISE | ノイズの量 |
| FILTER | LOWPASS / HIGHPASS / BANDPASS / OFF |
| CUTOFF / RESO | カットオフ周波数（40Hz〜18kHz）とレゾナンス |
| DRIVE | フィルターの前で歪ませる量 |
| VOLUME | 音量 |
| DLY TIME / DLY FDBK / DLY MIX | ディレイの時間（10ms〜1s）、フィードバック、原音に混ぜる量。時間を動かすとテープのようにピッチが揺れる |

ウェーブテーブルは起動時に倍音の数を変えた 9 段階を作っておき（10ms ほど）、音の高さに合わせて折り返しノイズが出ない段を使います。

プリセットは 15 種です（BRIGHT SAW / SOFT SINE / ACID SQUARE / DUB PLUCK / VIBRATO LEAD / HOLLOW PULSE / WARM PAD / WOOD FLUTE / NOISE WIND / VOWEL PAD / SYNC LEAD / FOLD BASS / DIGI KEYS / DRAWBAR ORGAN / MORPH PLUCK）。

### ドラム

- トラック 4 は最初からドラム（キット BASIC）です。どのトラックも INSTR 画面の TYPE でシンセとドラムを切り替えられます
- 8 パートの順番は KICK / SNARE / HAT / OPENHAT / CLAP / TOM / RIM / BELL です（自分のキットでも生成はこの順番を前提にします）
- 鳴らした音は最後まで（または END か KIL まで）鳴ります

#### 自分のキットを入れる

`samples/kits/` の下にフォルダを作って WAV を入れると、1 つのキットになります（実機では `roms/ports/knulli-first-synth/samples/kits/`）。

- ファイル名の順に、最初の 8 個がパッド 1〜8 になります。`1-KICK.wav` のように番号を付けると順番を決められ、画面には番号を除いた名前が出ます
- 対応形式：8/16/24/32bit の PCM と 32bit float。ステレオはモノラルにまとめます。サンプルレートは何でも構いません
- キットは起動時に読み込みます。入れ替えたらアプリを起動し直してください

A/B/X/Y の割り当ては SDL GameController の位置名に合わせています（A=下、B=右、X=左、Y=上）。そのため、本体の印字とはずれることがあります。

### 実機での確認結果（TrimUI Brick / Knulli）

Brick の内蔵パッドは、SDL GameController としてそのまま認識されます（生ジョイスティックのフォールバックは使われません）。

| 物理ボタン | SDL での名前 | アプリでの割り当て |
|---|---|---|
| 十字キー | DPUP / DPDOWN / DPLEFT / DPRIGHT | UP / DOWN / LEFT / RIGHT |
| ABXY | A / B / X / Y | A / B / X / Y |
| 背面 L1 / R1 | LEFTSHOULDER / RIGHTSHOULDER | L1 / R1 |
| 背面 L2 / R2 | トリガー軸 | L2 / R2 |
| 正面下部（左から） | GUIDE / BACK / START | MENU / SELECT / START |
| 正面中央上の 2 ボタン | LEFTSTICK / RIGHTSTICK | L3（ミュート） / R3（ソロ） |

### ボタンが反応しない・割り当てがずれるとき

割り当てのないボタンを押すと、画面最下部の行に受け取った入力が表示されます。

- `UNMAPPED PAD BUTTON ...`：SDL GameController として認識されているが、アプリで使っていないボタン
- `RAW JOY BUTTON n`：マッピングがないため、生の番号で受け取っている。`src/main.cpp` の `kRawJoyButtons` を実機の番号に合わせて直してください。もしくは、アプリと同じフォルダに `gamecontrollerdb.txt` を置けば読み込まれます。
